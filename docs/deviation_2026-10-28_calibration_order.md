# Deviation: calibration order (2026-10-28)

Plan reference: rubric Section 9 (calibration before formal scoring); analysis plan Section 5.

What changes: the second scorer (XH) is not available for a calibration discussion before formal scoring, and the submission deadline does not allow waiting.

Procedure instead:
1. XL completed the practice set (12 pilot responses) and the rubric Section 6 examples, and recorded provisional application rules in docs/calibration_record.md before starting formal scoring.
2. XL scores the primary set (96 responses) under those rules.
3. XH reads docs/calibration_record.md, then scores the practice set and the second-scorer set (20 responses) independently, without access to XL's scores.
4. Cohen's kappa is computed on pre-discussion scores, as in rubric Section 9. Disagreements are then discussed. If a provisional rule is changed, XL rescores the affected responses; rescored values are recorded with stage = final, and kappa is still reported on pre-discussion scores. If kappa < 0.70, the rubric's recalibration and rescoring rule applies.

Written before any primary-set response was scored.
